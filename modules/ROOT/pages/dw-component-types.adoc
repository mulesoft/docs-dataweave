= Component Types (dw::meta::Component)

This module defines the DataWeave types for component descriptors.

[%header, cols="1,2a,3a"]
|===
| Type | Definition | Description

| ComponentDescriptor
| `type ComponentDescriptor = { name: ComponentName, resources: { &#40;NameIdentifier&#41;: ModuleDescriptor }, flags?: { &#40;String&#41;: FlagDescriptor }, levels: { &#40;ComponentVersion&#41;: { &#40;ComponentName&#41;: { version: ComponentVersion, settings?: { &#40;String&#41;: Boolean } } } } }`
| Description of a `Component` that provides all metadata information.


| ComponentName
| `type ComponentName = String`
| Name of the `Component`.


| ComponentVersion
| `type ComponentVersion = String`
| Version of the `Component`.


| ComponentsDescriptor
| `type ComponentsDescriptor = Array<ComponentDescriptor&#62;`
| List of `Component` descriptors.


| FlagDescriptor
| `type FlagDescriptor = { name: String, description: String, creationVersion: String, deletionVersion?: String, behaviorChangeVersion: String, initialValue: Boolean, newBehaviorValue: Boolean }`
| Description of a `Flag` that provides all metadata information.


| ModuleDescriptor
| `type ModuleDescriptor = Object`
| Description of a `Module` that provides all metadata information.


| NameIdentifier
| `type NameIdentifier = String`
| Name of the `Module`.

|===
