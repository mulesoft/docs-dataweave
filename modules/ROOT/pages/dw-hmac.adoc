= HMAC (dw::util::jwt::HMAC)

This module provides functionality to create signed JSON Web Tokens using HMAC.

The supported HMAC algorithms are:

* HS256
* HS384
* HS512

Signing keys must be at least 256, 384, and 512 bits long for HS256,
HS384, and HS512, respectively.

To use this module, import it to your DataWeave code. For example,
by adding the line `import * from dw::util::jwt::HMAC` to the header of your
DataWeave script.

_Introduced in DataWeave version 2.6.0._
