= RSA (dw::util::jwt::RSA)

This module provides functionality to create signed JSON Web Tokens using RSA signatures.

The supported RSA algorithms are:

* RS256
* RS384
* RS512

RSA private keys must be unencrypted `PKCS#1` or `PKCS#8` PEM keys
with a modulus of at least 2048 bits.

To use this module, import it to your DataWeave code. For example,
by adding the line `import * from dw::util::jwt::RSA` to the header of your
DataWeave script.

_Introduced in DataWeave version 2.6.0._
